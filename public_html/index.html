Las correlativas se muestran con flechas que indican dependencias entre materias:

  • Flechas negras: requisito para cursar (asistencia/inscripción).
  • Flechas verdes: requisito para aprobar (condición para la calificación final).

Para los requisitos para aprobar hay dos estados:

  • Línea continua: la materia debe estar aprobada.
  • Línea punteada: la materia puede estar regularizada (no necesariamente aprobada).

Ejemplo:

Requisito para cursar - aprobado (negro, continuo)
Requisito para cursar - regularizada (negro, punteado)
Requisito para aprobar - aprobado (verde, continuo)
Requisito para aprobar - regularizada (verde, punteado)

Las materias se destacan con diferentes colores según su estado:

  • Azul - Promocionada: ambos parciales con nota ≥8 en el primer intento (o con un solo recuperatorio permitido).
  • Amarillo - Regularizada: ambos parciales con nota ≥6, pero aún no aprobaste el final.
  • Verde - Aprobada: final aprobado con nota ≥6.
  • Rojo - Desaprobada: agotaste las 3 oportunidades de recuperatorio con nota <6.

El sistema calcula automáticamente el estado de cada materia según las notas ingresadas:

  • Promocionada: ambos parciales con nota ≥8 en el primer intento. Se permite un solo recuperatorio si uno de los parciales tiene ≥8 y el otro <8, y con el recuperatorio se alcanza ≥8.
  • Regularizada: ambos parciales con promedio ≥6 (considerando hasta 2 recuperatorios por parcial). Permite rendir final.
  • Aprobada: materia regularizada con final aprobado (nota ≥6). Se pueden rendir hasta 4 finales.
  • Desaprobada: después de agotar las 3 oportunidades (1 parcial + 2 recuperatorios) en al menos un parcial con nota <6.
  • Debe recuperar: nota <6 en un parcial pero aún quedan recuperatorios disponibles.
  • En curso: faltan notas o exámenes por rendir.

El estado se actualiza automáticamente al ingresar las notas en el modal de cada materia.

En cada tarjeta de materia se muestran badges con información adicional:

  • Azul - Carga horaria: indica las horas semanales de cursada de la materia.
  • Verde - Nota final: muestra la nota final obtenida cuando la materia está aprobada.

Los badges te ayudan a identificar rápidamente la información clave de cada materia en el tablero.
